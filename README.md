# cbtone

Hawkish/dovish tone signals from **public** central-bank communication — dictionary,
transformer, local-LLM and fine-tuned scorers — plus evaluation tools that test whether those
signals carry information about future policy decisions and market reactions.

> **Status: under construction (Phase 1, building the corpus).** See `MISSION.md` and `docs/PROGRESS.md`.
